Notes that stay .txt

Fernwire moves your notes folder between laptop, phone and tablet. No database, no export button. Open any note in any editor, today or in 2046.

how it works
+------------------+         +-----------------+         +------------------+
| laptop           |         | relay           |         | phone            |
|  ~/notes/*.txt   |<=======>|  eu-2 or yours  |<=======>|  Files/notes     |
|  1,204 files     |  diffs  |  holds 0 bytes  |  diffs  |  1,204 files     |
+--------+---------+         +--------+--------+         +---------+--------+
         |                            |                            |
         +--- conflict? keep both: ----+--- note.txt + note~ipad.txt +
+-------------------+
| laptop            |
|  ~/notes/*.txt    |
+---------+---------+
          |  diffs
+---------+---------+
| relay  eu-2       |
|  holds 0 bytes    |
+---------+---------+
          |  diffs
+---------+---------+
| phone             |
|  Files/notes      |
+-------------------+

Only encrypted line diffs cross the wire. The relay forwards them and forgets; your files never leave your devices as a whole.
